# Unified A/B/C/D Prototype

Mở `index.html` bằng trình duyệt.

Prototype này gộp 4 solution option vào một giao diện tổng. A/B/C/D dùng cùng một layout và cùng thứ tự khối:

1. Bối cảnh
2. AI hỗ trợ
3. Người dùng quyết định
4. Kết quả mô phỏng

Chuyển option bằng thanh A/B/C/D phía trên hoặc các card ở màn hình Tổng quan.
